# 发布检查清单

每次发布（含 PATCH）重跑。可自动化的项做成门禁；其余逐条确认并留证据。

## 1. 发布前

| # | 检查项 | 证据 |
|---|---|---|
| 1 | 版本号与范围已确定 | 版本内容清单 |
| 2 | 范围已冻结；冻结后变更已记录 | 变更记录 |
| 3 | CHANGELOG 已更新 | `CHANGELOG.md` |
| 4 | PRD / 验收标准已同步 | 文档 diff |
| 5 | 所有 P0 验收用例通过 | 测试记录 |
| 6 | 无 blocker / critical 缺陷 | 缺陷清单 |
| 7 | 已知问题已记录 | 发布说明 |
| 8 | 文档中的版本、链接、命令已更新 | 文档检查记录 |

## 2. 版本一致性门禁

| # | 检查项 |
|---|---|
| 1 | `VERSION` == 预期版本 |
| 2 | CHANGELOG 存在 `## [X.Y.Z]` |
| 3 | tag 未创建或指向正确提交 |
| 4 | Release 标题为 `AudioUI vX.Y.Z` |
| 5 | 产物名为 `audio-ui-vX.Y.Z-win64.zip` |
| 6 | README 与文档中的版本引用一致 |
| 7 | 应用内版本号显示一致 |

任一项不一致，拒绝发布。

## 3. 构建

| # | 检查项 | 证据 |
|---|---|---|
| 1 | 干净工作区，无无关改动 | `git status` |
| 2 | 前端构建成功 | 构建日志 |
| 3 | Go/Wails 构建成功 | 构建日志 |
| 4 | 版本号已注入 | 启动后关于页/日志 |
| 5 | runtime 资源完整 | 目录清单 |
| 6 | 绿色包结构正确 | zip 内容 |
| 7 | 生成 SHA-256 | `checksums.txt` |
| 8 | 病毒扫描（可选） | 扫描报告 |

## 4. 测试

| # | 检查项 | 证据 |
|---|---|---|
| 1 | 单元测试通过 | 日志 |
| 2 | 集成测试通过 | 日志 |
| 3 | 协议回放测试通过 | 日志 |
| 4 | golden frame 对比通过 | 截图/差异 |
| 5 | 干净 Windows 冒烟通过 | 手工记录 |
| 6 | 不写 AppData | 启动前后目录对比 |
| 7 | 日志落在 exe 目录 | 目录截图 |
| 8 | WebView2 正常 | 启动截图 |
| 9 | CLI 检测与提示正确 | 手工记录 |
| 10 | 会话 resume / 新开会话 | 手工记录 |
| 11 | 并发、排队、取消、停止 | 手工记录 |
| 12 | 删除级联与回收站恢复 | 手工记录 |
| 13 | 导出 MP4/SRT，剪映可导入 | 手工记录 |

## 5. 发布

| # | 检查项 | 证据 |
|---|---|---|
| 1 | 创建 annotated tag | `git tag -v` |
| 2 | 创建 Release | Release 页面 |
| 3 | 上传 zip 与 checksums | Release 资产 |
| 4 | 发布说明（客户版/内部版） | 发布说明 |
| 5 | 下载链接为完整路径 | 链接检查 |

## 6. 发布后

| # | 检查项 | 证据 |
|---|---|---|
| 1 | 下载、解压、启动 | 验证记录 |
| 2 | 版本号显示正确 | 截图 |
| 3 | 日志与数据目录正确 | 截图 |
| 4 | 至少一条链路可用 | 验证记录 |
| 5 | 归档：zip、checksums、说明、清单 | 归档记录 |
| 6 | 更新 CHANGELOG 与文档 | 提交记录 |
| 7 | 记录已知问题与后续计划 | 发布说明 |
