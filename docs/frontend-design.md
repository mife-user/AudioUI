## 1. Overview

> **目标交互（M2-11～13；M2-12A 已验收，M2-12B 已验收）**：本地候选节点、只构建任务的提示词、独立 Agent 节点与 `script` 输出版本，见 [4.8](#48-m2-11-13-本地脚本工作流设计已验收) 和[单文件演示](design/m2-11-13-local-flow-demo.html)。云端与视频仍待评估。4.7 及之前说明 M2-00～10 旧模型和已验收行为，不代表新目标已交付。

AudioUI 是一个桌面端节点图工作台。前端承担三件事：

1. **画布**：展示工作台、节点、链路、状态。
2. **交互**：选题、提示词、待应用产物、权限确认、队列。
3. **渲染**：场景 DSL 预览与视频导出。

设计目标：**科技但沉稳**。信息密度高，但层级清楚；强调色只出现在状态与操作上；长时间盯画布不疲劳。

设计原则：

1. 结构产生科技感，不靠霓虹与重发光。
2. 大面积低对比，重点小面积高对比。
3. 1px 细线为主，阴影只用于浮层。
4. 动效短、方向一致、不做弹跳。
5. ID、版本、命令一律等宽。
6. 颜色不是唯一信号：状态同时用文字或图标。
7. 提示词只在提示词节点输入，交互栏不提供输入框。

非目标：移动端完整适配、触屏优先布局、富文本编辑器、通用剪辑界面。

颜色纪律：

- 强调色只用于：选中、可操作、链接、活动态。
- 不使用大面积强调色填充。
- 状态色必须配文字或图标。
- 深色主题需单独检查对比度，不能由浅色推断。

### 3.3 字体

| 角色 | 字体 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| 页面标题 | Inter / Noto Sans SC（B 用 Noto Serif SC） | 18px | 1.25 | 650 |
| 区块标题 | 同上 | 16px | 1.3 | 650 |
| 节点标题 | Inter / Noto Sans SC | 11.5px | 1.4 | 650 |
| 正文 | Inter / Noto Sans SC | 13px | 1.5 | 400 |
| 次级 | 同上 | 11.5px | 1.5 | 400 |
| 标签 / 元信息 | 同上 | 10px | 1.4 | 500，字距 .08em |
| 等宽 | JetBrains Mono / Consolas | 10.5px | 1.5 | 400 |

规则：

- 节点标题保持无衬线，保证扫读。
- B 主题的页面标题、区块标题可用衬线；正文仍无衬线。
- 中文优先使用 Noto Sans SC；字体必须随包，不依赖系统。
- 数字、ID、版本、命令使用等宽。

### 3.4 间距

4 / 8 / 12 / 16 四档：`--s1` ~ `--s4`。紧凑模式覆盖为 3 / 6 / 9 / 12。

| 用途 | 舒适 | 紧凑 |
|---|---|---|
| 图标与文字 | 4 | 3 |
| 组件内边距 | 8 | 6 |
| 区块间距 | 12 | 9 |
| 页面边距 | 16 | 12 |

### 3.5 圆角、边框、阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 5px | chip、按钮、输入框 |
| `--radius` | 9px | 节点、卡片、面板 |
| `--radius-lg` | 14px | 弹窗、抽屉（少用） |

- 默认 1px 边框；hover 使用 `--border-strong`。
- 阴影只用于浮层：节点、快捷栏、调度面板、设置抽屉、弹窗。
- 静止元素不发光；选中元素用 1px 强调色描边 + 极轻光晕。

### 3.6 动效

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover / focus | 140ms | ease-out |
| 折叠 / 展开 | 180ms | ease-out |
| 主题切换 | 200ms | ease |
| 提示 toast | 150ms 进入 / 150ms 离开 | ease-out |

规则：

- 不做弹跳、不做大幅位移。
- 展开与收起方向一致。
- 尊重 `prefers-reduced-motion`；减少动效不得影响功能。

| Script | 270 × 205 |

缩放范围建议为最小 200 × 140、最大 1200 × 900。卡片的 `position + size` 作为一组工程布局数据，通过单次原子布局命令保存；仅改布局不改变图拓扑、上下文哈希、产物、stale 或运行锁。开发期工程数据不要求兼容或迁移，已有开发工程可丢弃。

**新建入口**：移除画布左上角「新选题」「草稿提示词」按钮。空白画布右键菜单与键盘等价入口创建 Topic、Prompt、Agent、Script；以 `screenToFlowPosition` 将触发时的屏幕坐标映射为画布落点，菜单自身在当前视口内避边。除 Topic 外均为无父草稿，Candidate 仍仅由 Topic 自动生成。方向键、Home/End、Enter、Escape 可操作菜单；文本输入区右键保留系统菜单。快捷栏「新建节点」复用同一菜单并从画布中心打开；成功后选中新卡但不移动视口。节点右键菜单、命令面板不在本批；既有双击聚焦保留。

**Agent 栏和请求归属**：Agent 栏默认收起为悬浮状态入口；展开面板有界且可滚动，不占画布列宽。展开面板可通过标题栏拖动，收起态胶囊可在非按钮区域拖动；两态均可聚焦后用方向键移动。两态共享本次应用会话内的位置，并按当前尺寸及视口重新避边；窗口大小变化时再次夹取，重启恢复默认右上角，不写工程数据。权限、问题及待确认结果按冻结的 project/run/request/pending 身份定位到关联节点；面板收起不自动授权或丢弃请求，无法定位时提供异常恢复入口。U11 用户于 2026-11-10 确认实际页面验收通过；助手未启动浏览器。

**Script 预览（U5 已实现并通过用户验收）**：已有 Script 的新结果归属由发送时冻结的输出绑定决定，不按实时连线推断。Script 卡片显示待确认入口，先读取并完整预览新内容、来源和基准版本，再确认追加或丢弃；版本冲突不提供 force。无绑定自动创建节点及空 Script 自动写入首版的规则不变。最新正文摘要由工程/节点/版本作用域查询取得，全文和历史版本按需读取；返回内容只作为转义文本显示，工程切换后忽略迟到响应。服务端校验工程、Script 节点、版本与 CAS 关系，并验证大小、UTF-8 和 `script@1` Schema，不接受任意 artifact hash。待确认预览、确认、丢弃、冲突和仅重试同步共用工程作用域控制器。助手未完成真实浏览器实测或归档截图/viewport；真实 Agent 与 WebView2 平台行为未覆盖。

**连线与排布（U7 历史基线，已通过用户验收）**：自定义 Edge 在无阻挡的前向连接中绘制曲线，在反向、间距不足或卡片阻挡时尝试有界绕行；按当前节点矩形避让，失败时稳定回退。可见方向箭头，透明命中区 20px；当前路径与运行锁状态独立呈现，并区分连接拖拽与无效目标。叶子链仅以 Go 快照为准，共享前缀不误选第一条分支；切换继续只调用 `SelectNode`。自动 Candidate/Script 及前端新增子节点按保存尺寸、默认尺寸和 36px 间距确定性避让，不移动既有节点；用户指定坐标不改动。Go 仍是连接与改挂合法性的唯一校验方。实现和定向自检通过，真实浏览器页面未测。

**连线弧线（U10，已于 2026-11-10 通过用户验收）**：正向可用路径采用三次贝塞尔；反向、窄间距或受卡片阻挡时使用带圆角过渡的复合曲线，并采样检查当前节点矩形。拖线预览与已连接边共享路由和实时节点尺寸；箭头、20px 命中区、路径高亮、运行锁样式及无效连接提示保留。没有可行避让路径时以平滑贝塞尔曲线退化并保留真实端点，密集布局可能与卡片相交。用户已完成界面验收；助手未代为操作真实页面。

**U12 已于 2026-11-12 通过用户验收；U13～U16 新增交互（主要目标已确认，未实现）**：见[单文件原型](design/u10-u16-canvas-optimization-demo.html)与[任务计划](plans/active/canvas-workbench-optimization-plan.md)。用户确认去掉的是卡片**缩放控制框线**，普通卡片边框、局部缩放手柄、八向命中区及焦点提示保留；节点正文可折叠，Topic 候选及固定连接锚点可见。目标画布允许各阶段有向连接、多个上游但禁止成环；独立 Prompt → Agent 的有效任务可无 Topic 运行。执行时检查实际输入与目标契约，不兼容须说明而不删除连线；原型中的单主任务只是文本任务示例，不是所有节点的限制。已有结果默认确认后追加版本，也可显式新建并行结果；每个下游输入固定版本，预览标签不能暗中修改绑定。Topic 再次生成先预览新批次，确认后创建独立候选并保留旧来源。输入角色/次序及交互细节仍须评审；上述目标不等于当前 M2 行为已改变，原型不作为产品验收证据。

**输入与运行前保存**：自动保存不禁用正在输入的控件；IME 组合结束后再保存，旧响应不能覆盖新草稿。启动 Agent 只 flush 根到目标节点的路径前缀及受保护输出；下游和无关分支不得误锁或阻止运行。工程切换、失败与仅重试快照均保留明确状态。

详细行为与 AC-U-01～20 见[优化计划](plans/active/canvas-workbench-optimization-plan.md)和[验收标准](acceptance.md)。U5 已实现并经用户确认验收；U6 原范围及标题栏拖拽补充项、U7 均于 2026-11-10 通过用户验收；U10 已通过用户验收；U11 用户于 2026-11-10 确认实际页面验收通过（助手未启动浏览器）；U12 已于 2026-11-12 通过用户页面验收，整文件测试无进度并已停止（见[自检证据](dev/evidence/u12-resize-outline.md)）；前端全量测试受 Node.js 堆上限影响未通过，U7 真实页面操作未测；U8～U9 尚未实施。

### 5.1 NodeCard

```text
┌──────────────────────────────┐
│ 类型 / 标题          [状态]  │
├──────────────────────────────┤
│ [chip] 参数                  │
│ [chip] 约束                  │
│ ┌──────── 预览 ───────────┐  │
│ │                         │  │
│ └─────────────────────────┘  │
└──────────────────────────────┘
```

- 默认：`--panel` 背景、1px `--border`。
- hover：`--border-strong`。
- selected：1px `--accent` 描边 + 轻光晕。
- draft（无父 prompt）：虚线边框 + 「未连接」chip；不可执行。
- pending：`--warn` chip「待应用 n」；节点内容不变。
- locked：`--muted` 锁图标 + 标题「已锁定」；内容输入与执行按钮禁用，只保留新增下游节点入口。
- stale：`--warn` 左边框 + 「待刷新」文案。
- error：`--danger` 左边框 + 错误文案。
- running：状态点 + 「执行中」；只读。
- disabled：50% 不透明度，禁用指针。
- 预览区懒加载；无预览时显示占位骨架，不显示空白。

## 6. 交互状态

每个可交互元素至少覆盖以下状态；不能只交付默认态。

| 状态 | 视觉变化 | 触发 |
|---|---|---|
| default | 基础边框、常规文字 | 静止 |
| hover | 边框变 `--border-strong`；指针变化 | 鼠标进入 |
| focus | 2px 焦点环，颜色 `--accent`，不裁切 | Tab / 点击 |
| active | 背景 `--accent-soft`；边框 `--accent` | 按下 / 选中 |
| disabled | 50% 不透明度；`cursor: not-allowed` | 不可用 |
| loading | 骨架或 16px 旋转指示；禁止重复提交 | 请求中 |
| empty | 图标 + 一句说明 + 主操作 | 无数据 |
| error | `--danger` 文本 + 可执行建议 | 失败 |
| success | `--ok` 文本或 toast；2 秒后回落 | 成功 |

补充：

- 折叠/展开：箭头方向与状态一致；动画 180ms。
- 主题切换：只改 CSS 变量，不重建组件树。
- 减少动效：关闭过渡与动画，但保留状态变化。
- Toast 不阻塞操作；同一时间最多一条。
- 权限确认 120 秒超时，超时视为拒绝，并显示"已超时"；"允许本次运行"只对非高风险操作开放。
- 运行中切换链只切视图，不中断运行；运行记录按 runId 分组，不被旧链事件污染。

## 7. 边界情况与约束

| 场景 | 规则 |
|---|---|
| 空画布 | 显示 EmptyState，主操作「新建选题」 |
| 图命令已提交但快照同步失败 | 显示已保存但未同步，保留待同步 receipt 并阻止重复写；「仅重试快照同步」成功后才呈现节点/边并解除阻塞 |
| 无链路 | 快捷栏显示「暂无链路」，不占高度 |
| 链路很多 | 快捷栏横向滚动；折叠态显示计数 |
| 节点标题过长 | 单行省略，hover 显示完整标题 |
| 参数文本过长 | 换行，最多 3 行，超出省略 |
| 草稿节点 | 虚线「未连接」；不能执行；可被任意输出端口接入 |
| 锁定节点 | 内容编辑与再次执行禁用；非运行链可改挂；移动/新增子节点视运行锁而定 |
| 改挂已有父 | 弹确认：显示子树节点数与「该节点与后代上下文将变化」；确认后移动；取消则回弹；同一 topic 换候选同样确认并提示候选变化 |
| topic 候选未应用 | 候选端口禁用并提示「先应用候选」；应用后每个候选端口可用 |
| 运行/排队路径 | 路径节点与共享祖先只读；路径外兄弟分支可编辑 |
| 运行中断 | 运行记录标记 `interrupted`；可重新执行节点 |
| 上下文超预算 | 显示估算值与预算；按祖先降级；仍超则拒绝执行 |
| 已有运行在途 | M2 返回 `BUSY` 并提示；队列在 M5 |
| 渲染失败 | 保留旧预览，显示错误态与重试 |
| CLI 缺失 | 禁用 Agent 相关操作，显示安装指引 |
| 设备像素比 | 1x/1.5x/2x 下边框与图标不模糊 |
| 窗口缩小 | 低于 1200px 时交互栏移到下方；低于 1024px 提示最小尺寸 |
| 文本放大 200% | 不重叠、不裁切；允许画布滚动 |
| 多显示器 | 记住窗口位置；不在屏幕外打开 |

## 8. 响应式与窗口

桌面优先，不做手机完整适配。

| 宽度 | 布局 |
|---|---|
| ≥ 1280 | 画布 + 右侧 322px 交互栏 |
| 1024 – 1279 | 画布 + 交互栏移到下方，快捷栏保持浮动 |
| < 1024 | 提示最小窗口尺寸；不允许内容错位 |

规则：

- 画布用平移/缩放适配，不重排节点。
- 文本容器使用 `min-width: 0`，避免溢出。
- 不使用固定 px 的整页容器。
- 允许系统字体缩放；正文对比度不降低。
- 桌面点击目标 ≥ 32px；未来触屏 ≥ 44px。

## 9. 可访问性

| 项 | 要求 |
|---|---|
| 对比度 | 正文 ≥ 4.5:1；次要文字 ≥ 3:1；状态色配文字 |
| 键盘 | 所有操作可 Tab 到达；焦点可见；顺序与视觉一致 |
| 语义 | header/main/nav/aside/footer；按钮用 button；折叠用 aria-expanded |
| 图标 | 图标按钮必须有 aria-label |
| 状态 | 状态点必须配文字，不能只靠颜色 |
| 动效 | 尊重 prefers-reduced-motion |
| 弹层 | 打开时焦点进入；Esc 关闭；关闭后焦点回到触发点 |
| 提示 | toast 使用 aria-live="polite" |
| 画布 | 真实 React Flow DOM 自动化验证节点可聚焦，Enter/Space 可选中；方向键移动持久化与可见区域仍须在 WebView2 手工验收 |
| 图表 | 预览图提供文字摘要或替代文本 |

## 10. 性能预算

| 指标 | 目标 |
|---|---|
| 冷启动 | ≤ 3 秒（参考机） |
| 画布交互 | 60fps；节点 ≤ 200 时无明显掉帧 |
| 主题切换 | ≤ 50ms，不触发整树重渲染 |
| 设置切换 | ≤ 100ms |
| 预览图 | 懒加载；单张 ≤ 300KB；缩略图 WebP |
| 首屏 JS | ≤ 300KB gzip（不含原型与调试） |
| 内存 | 3 个活跃会话 ≤ 1.5GB |
| 渲染防抖 | 300–500ms；只刷新最近下游节点 |

实现约束：

- Zustand 使用选择器，避免整 store 订阅。
- 节点组件 `memo`；预览组件懒加载。
- 长列表虚拟化（链路 / 队列）。
- 主题切换只用 CSS 变量。
- 不在渲染循环里创建对象；`draw(t)` 保持纯函数。

## 12. 资源与字体

| 资源 | 约定 |
|---|---|
| 字体 | Inter、Noto Sans SC、Noto Serif SC（仅 B 标题）、JetBrains Mono |
| 图标 | SVG，单色，`currentColor` |
| 图片 | WebP / AVIF；提供 1x / 2x |
| 预览 | 由渲染器生成；不手工切图 |
| 空状态 | 图标 + 文案 + 主操作，不用大插画 |
| 禁止 | 用 emoji 当图标；把文案烘焙进图片 |

### 12.1 字体子集与随包策略

决定：只随包 WOFF2 子集，不打包完整字体。

| 字体 | 用途 | 子集 | 预算 |
|---|---|---|---|
| Inter | 拉丁正文、数字 | Latin + 标点 | ≤ 120KB |
| Noto Sans SC | 中文正文、节点、按钮 | UI 文案 + GB2312 一级字（3755）+ 常用标点 | ≤ 3.5MB |
| Noto Serif SC | 仅 B 主题页面/区块标题 | 常用标题字 + 标点 | ≤ 2.5MB |
| JetBrains Mono | ID、版本、命令 | Latin + 符号 | ≤ 60KB |

规则：

- 构建期用 `pyftsubset` / `glyphhanger` 生成子集；提交子集文件与 OFL 许可证，不提交源字体。
- 脚本扫描前端文案，校验 UI 字符覆盖率；缺字直接失败。
- 用户输入的罕见字允许回退系统字体，不阻塞。
- 回退栈：`Noto Sans SC → Microsoft YaHei → sans-serif`；B 标题：`Noto Serif SC → Source Han Serif SC → SimSun → serif`。
- 正文预加载；`font-display: swap`；首屏用轻量启动层避免 CLS。
- 总字体预算 ≤ 8MB；超过则先裁减 serif 子集。
- 验收：首屏无字体闪烁、200% 缩放不重叠、罕见字回退可读。
