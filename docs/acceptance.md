# 验收标准

> 约定：每条验收用例使用 Given-When-Then，必须可测试、无歧义、覆盖异常。
> 发布门禁：所有 P0 用例通过；冒烟测试通过；无 blocker。

## 0. M2-11～13 本地脚本目标验收（M2 整体验收已于 2026-11-08 通过用户确认）

本组用例对应 PRD F-04/F-05/F-07/F-15/F-17 和本地 F-18，仅覆盖本地 Agent 与现有 `topics`/`script` Schema。M2-00～10 已验收旧模型证据不覆盖本组用例。M2-11D 自检证据见 [M2-11D 自检记录](dev/evidence/m2-11d.md)，只说明 workflow/MCP/persistence 组件及对应自动化用例，不等于 AC-T-01～10/18/19 全量通过或 M2-13 集成验收。M2-12A/B 已由用户验收；M2-13 已于 2026-11-08 通过用户验收，其自检范围及本次自检未执行项见 [M2 集成与 AC 状态证据](dev/evidence/m2.md)。RM-019 云端 AC-T-11～15/17 及 RM-020 视频专项 AC-T-04 保留为待评估，不计入当前 M2 出口；脚本用例通过不能替代视频 AC。

| 用例 | Given / When / Then |
|---|---|
| AC-T-01 | Given 可运行的选题节点，When 本地 Agent 返回符合现有 `topics` Schema 的结果，Then 应用原子保存不可变来源产物并生成对应候选节点；每个候选绑定来源 artifact 与 0 基索引，选题内容/执行按规则锁定。若结果无效则不生成候选节点。 |
| AC-T-02 | Given 提示词未连接 Agent，When 用户尝试执行提示词，Then 不启动运行并提示连接 Agent；连接后仅由 Agent 节点启动本地运行，提示词提供任务与约束。 |
| AC-T-03 | Given Agent 有一个已指定但尚无版本的脚本输出节点，When 收到符合 `script` Schema 的 `reply`，Then 应用自动写入首个不可变版本并关联原运行，不要求人工确认，也不自动执行下游。 |
| AC-T-04 | Given 视频输出节点或视频产物，When 执行视频专属校验/渲染，Then 本阶段无对应通过结论；该用例暂缓至 RM-020 范围评审，不得用脚本 Schema 测试替代。 |
| AC-T-05 | Given Agent 没有指定输出节点，When 收到符合 `script` Schema 的合法 `reply`，Then 应用在命令层原子创建一个直接脚本子节点并关联结果与运行来源，无需人工确认；新节点不自动运行。 |
| AC-T-06 | Given `reply` 类型不在本地允许范围、payload 不符合 Schema、节点越权、运行已失效或契约不匹配，When 应用处理结果，Then 不改变图或输出版本，呈现稳定错误并保留有界诊断证据。 |
| AC-T-07 | Given 同一运行的合法 `reply` 被重试/重放或写入中途发生故障，When 恢复或重复接收，Then 同身份同内容只产生一个节点/关联/版本；同一运行不同内容或身份冲突时明确拒绝；不能出现半个节点或假报成功。 |
| AC-T-08 | Given 提示词/Agent 子树从候选 A 改挂到候选 B，When 再次启动 Agent，Then 新上下文只按新路径构建并包含 B、当前提示词与约束；此前运行及已产出脚本仍保留原路径来源。 |
| AC-T-09 | Given Agent 已发送运行，When 后续图关系或输出绑定发生变化，Then 运行的路径、候选/产物版本、提示词、输出目标与 `script` 契约版本仍是发送时快照；迟到或归属不匹配结果不得写入新路径/目标。 |
| AC-T-10 | Given Agent 已有一个直接脚本输出节点或运行正在使用该输出契约，When 用户尝试增加第二个直接输出或更改在途绑定，Then Go 图命令/运行锁拒绝该操作；一个 Agent 不得同时绑定多个直接输出。 |
| AC-T-11 | Given 同一任务与可用能力，When 选择本地或云端 Agent，Then 二者均遵守相同的应用输出契约与 `reply` 写图规则，差异能力明确报告。（RM-019，暂缓） |
| AC-T-12 | Given 云端运行需要本地素材，When 用户未选择上传，Then 云端不能读取该本地文件；选择上传后，文件只对获授权的用户和运行可用。（RM-019，暂缓） |
| AC-T-13 | Given 云端 Agent 使用自身提供的文件、Bash 或搜索工具，When 执行，Then 文件与 Bash 在该运行的云端工作区执行，搜索由 Agent 或其服务提供，通用工具不要求代理到用户电脑。（RM-019，暂缓） |
| AC-T-14 | Given 云端连接中断、请求重试或取消，When 连接恢复或返回迟到结果，Then 不重复创建节点或跨用户/跨运行写入；状态和未完成结果明确可见。（RM-019，暂缓） |
| AC-T-15 | Given 两个云端用户或两次独立运行，When 一方尝试访问另一方文件、凭据、任务或结果，Then 服务端拒绝。（RM-019，暂缓） |
| AC-T-16 | Given 一次运行已绑定发送时的路径和产物版本，When Agent 经应用接口查询图或产物，Then 只返回该运行快照授权的数据；对应版本不可用时明确失败，不混入改挂后的实时数据。 |
| AC-T-17 | Given 用户未登录或无权访问某云端运行，When 发起运行或读取其文件与结果，Then 服务端拒绝；合法用户只能访问自己获授权的资源。（RM-019，暂缓） |
| AC-T-18 | Given 指定脚本输出节点已有版本，When 收到合法 `script` reply，Then 先创建绑定当前版本的待确认结果；用户确认后仅在该版本仍匹配时追加新版本并保留旧版本及其 artifact；取消不改变旧内容；版本已变化时返回冲突且不覆盖。 |
| AC-T-19 | Given 新模型图，When 用户连接节点或从候选/脚本结果建立后续分支，Then 仅允许 `topic → candidate`（应用生成）、`candidate → prompt`、`prompt → agent`、`agent → script`、`script → prompt`；候选与脚本可分别有多个提示词分支，所有其他类型组合由 Go 拒绝。 |

云端用例可在 RM-019 纳入后重新排期；AC-T-04 视频专项需另行确定视频节点/产物、执行安全与渲染导出边界。

### M2 图与提示词

| 用例 | 内容 |
|---|---|
| AC-M2-1 | Given 空画布，When 新增/连接/改挂节点，Then 单父、无环、非自身、topic 根校验生效，改挂移动整个子树 |
| AC-M2-2 | Given 提示词节点已应用首轮，When 尝试编辑内容或再次执行，Then 编辑与执行均被拒绝；可新增提示词节点或分支继续 |
| AC-M2-3 | Given 一次运行通过 MCP `reply` 返回结构化结果，When 未点击应用，Then 仅创建 pending、节点内容不变；Schema 无效时原始 payload 与校验错误仍可查询，Agent 不能应用或改图 |
| AC-M2-4 | Given 点击应用，When 上下文与参数校验通过，Then 产生新轮次且下游标记为待刷新 |
| AC-M2-5 | Given 多条叶子链，When 切换链路，Then 视图切换且不占并发；另一链运行中执行返回 `BUSY` |
| AC-M2-6 | Given 已有父的提示词节点，When 端口拖拽改挂（含跨 topic 树或同一 topic 换候选），Then 提示影响面；确认后移动子树（同父换候选不移动子树）并迁移 steps；自连、成环、topic 作子节点被拒；源/目标树运行锁均生效 |
| AC-M2-7 | Given 0.2.0 数据，When 首次启动 0.3.0，Then 默认工程含旧对话（只读运行）与工作区副本，原文件保留 |
| AC-M2-8 | Given 分支路径，When 执行节点，Then 上下文只含该路径祖先最新轮次与所选候选，不含目标历史/兄弟/子节点；工作区文件只提供路径与大小，不注入文件正文，二进制资源仅引用；相同输入哈希一致 |
| AC-M2-9 | Given 运行中关闭应用，When 重启，Then 该运行标记 `interrupted`，历史可回看，不自动 resume |
| AC-M2-10 | Given 上下文估算超过 `contextTokenBudget`（默认 1,000,000），When 执行，Then 按祖先从远到近降级、直接父最后；目标参数保持完整；仍超则拒绝并返回估算值与预算 |
| AC-M2-11 | Given 运行/排队路径，When 编辑该路径节点、改挂或新增子节点，Then 拒绝；路径外兄弟分支可编辑；Agent 内置 Read/Glob/Grep 只可读该运行路径的祖先/当前节点 steps，Write/Edit 只可写当前运行节点 steps；MCP 文件读取只返回当前路径叠加及 exe 同级 runtime 的可见内容，兄弟节点、其他 topic 树与越界内容不可见 |
| AC-M2-12 | Given topic 的多个候选端口，When 分别连接分支并执行，Then 每条分支的上下文取对应候选；同一候选的分支共享该候选；`read_artifact` 只返回该路径所选候选对象，按 UTF-8 字节边界分块，路径外或重复 ID 视图冲突时拒绝 |

> M2 的 topic/prompt 节点应用后即锁定内容与执行，每节点最多一个已应用轮次；继续迭代通过新增下游节点或候选端口分支。`SelectNode` 与快捷栏切换只改视图，不递增图 revision、不广播快照。

### 工作台交互优化（独立批次；U0 已确认）

本批次安排在 M2 验收之后、M3 开始之前；不修改既有 M2 验收结论。具体流程与测试覆盖见[画布交互优化计划](plans/active/canvas-workbench-optimization-plan.md)。

| 用例 | 内容 |
|---|---|
| AC-U-01 | Given 正在编辑 Topic 或 Prompt，When 停顿超过 320ms 而自动保存开始，Then 输入框不被禁用、不丢焦点，继续输入与光标位置正常。 |
| AC-U-02 | Given 首次保存仍在途且用户继续输入，When 旧回执和旧快照先到，Then 最新草稿不回退；最终保存最新内容，重新打开工程后内容一致。 |
| AC-U-03 | Given 中文输入法正在组合、粘贴长文本或输入 Emoji，When 自动保存计时触发，Then 不提交不完整组合、不截断内容、不重复字符。 |
| AC-U-04 | Given 写盘失败、快照同步失败、工程切换或启动运行，When 仍有未保存/未同步草稿，Then 草稿保留并提示；运行不能使用旧值，提交成功的操作不重复写。 |
| AC-U-05 | Given 任意五类卡片，When 从四边及四角缩放，Then 对应指针、边界和锚点正确，正文可滚动，端口/边跟随，不误触拖动与连线。 |
| AC-U-06 | Given 使用当前开发格式的工程已调整卡片大小和位置，When 关闭并重新打开该工程，Then 两者一致恢复；既有开发工程不要求迁移或兼容。 |
| AC-U-07 | Given 运行路径已锁定，When 用户只调整卡片布局，Then 内容/拓扑锁仍有效，而视图调整不改变上下文哈希、结果绑定和内容。 |
| AC-U-08 | Given 画布已平移或缩放，When 在空白处右键并选 Prompt，Then 新草稿左上角位于该右键的画布坐标，不隐式连接、不自动挪到屏幕中心。 |
| AC-U-09 | Given 菜单靠近窗口边缘或使用键盘，When 打开并选择类型，Then 菜单保持可见，方向键/Enter/Escape 可用；输入框右键仍可使用文本菜单。 |
| AC-U-10 | Given 空画布，When 用户需要创建节点，Then 左上角无原有两个创建按钮，但右键和键盘可创建；Candidate 标明由 Topic 自动生成。 |
| AC-U-11 | Given 已有 Script v1 收到合法 v2 结果，When 点击原输出卡片右上角待确认入口，Then 可查看内容、目标和基准并确认追加或丢弃；确认后 v1 保留，版本冲突不提供 force。 |
| AC-U-12 | Given 待确认结果绑定旧 Script，When 该 Script 改挂且 Agent 后接入新 Script，Then 待确认标识仍指向冻结目标/异常恢复路径，不误指新 Script；后端拒绝不匹配确认。 |
| AC-U-13 | Given 长 transcript、很多分支和窄窗口，When 展开悬浮 Agent 栏或缩放画布，Then 面板内容可完整滚动、操作可达；卡片、端口和线条没有被固定侧栏挤出不可访问区。 |
| AC-U-14 | Given 多条共享前缀的叶子链，When 切换或移动/缩放节点，Then 高亮的路径、箭头和端口正确，非当前分支仍可辨认；切换不改图 revision、不占运行槽。 |
| AC-U-15 | Given 权限请求或 `ask_user` 存在，When Agent 栏收起或节点在画布外，Then 状态入口仍可定位到对应节点并处理；请求身份、超时、拒绝和审计语义不变。 |
| AC-U-16 | Given 正在输入的工程 A 切换至工程 B、运行事件乱序或同步失败，When 旧异步结果返回，Then 不能污染 B、丢失未决请求或把旧内容覆盖为新状态。 |
| AC-U-17 | Given 选题一次生成多条候选且周围已有不同尺寸卡片，When 自动放置节点，Then 新节点按确定性规则互不重叠、不移动已有节点；分支、来源和事务保持正确。 |
| AC-U-18 | Given 本地 Agent 执行环境报告有或没有网页搜索能力，When 用户发起需搜索的任务，Then 可用能力及权限需求明确；搜索由 Agent 提供，不经新增通用 MCP 代理；未授权不得在测试中访问外网。 |
| AC-U-19 | Given `Prompt A → Agent A → Script A → Prompt B` 中 Prompt B 有未保存或无效草稿，When 用户启动 Agent A，Then 仅 flush 根到 Agent A 的相关输入，Prompt B 不被强制保存或阻止本次启动；提交阶段仅临时锁定该前缀及须保护的绑定输出 Script A，Prompt B 和其他无关分支不被误锁，最终以 Go 的权威锁为准。 |
| AC-U-20 | Given Agent 运行面板已展开，When 用户拖动标题栏（不含操作按钮）或聚焦标题栏后用方向键移动，Then 面板保持在应用窗口可视范围内；按钮点击不触发拖动，收起再展开保留本次会话位置。 |

## 2. 功能验收（AC 编号对应 PRD）

> AC-01～14、AC-M2-1～12 保留 M2-00～10 旧模型及已验收历史事实；与 M2-11～13 新目标重叠时，不替代 AC-T-01～03、05～10、18～19。新目标待评审和实现，旧证据不得作为新目标通过证据。

| 编号 | 验收要点 |
|---|---|
| AC-01 | 新建/打开/切换项目；重启后恢复 |
| AC-02 | 拖拽平移、滚轮缩放；节点位置持久化 |
| AC-03 | 单父约束；自由改挂（含同一 topic 换候选确认）；整条路径高亮；快捷栏按叶子链切换不占并发、不触发图变更 |
| AC-04 | 输入想法 → 候选 ≥3 → 应用 → 候选端口连线建分支；可多个候选、同一候选可再分叉 |
