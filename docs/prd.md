### 1.1 新目标需求（M2 本地脚本子范围已选定，设计已验收，完整闭环未完成）

> M2-00～10 按旧模型完成并保留原验收事实；后续目标不追认旧证据。用户选择把 RM-018 中候选节点、提示词/Agent 分离、受限 `reply` 自动建脚本输出节点及发送时上下文纳入 M2-11～13，仅限本地执行与现有 `script` Schema。M2-11A 设计稿已于 2026-11-06 由用户验收；M2-11B 工程格式与图领域模型已于 2026-11-06 通过用户验收；M2-11C 已于 2026-11-07 验收；M2-11D 已于 2026-11-07 通过用户验收；M2-12A 已于 2026-11-08 通过用户验收，M2-12B～13 尚未开始，完整目标闭环未完成。云端能力（RM-019）和视频输出/渲染导出（RM-020）仍待评估，不属于本批范围。详细任务和阶段门禁见 [M2 目标闭环计划](dev/m2-target-closure-plan.md)。

**目标流程**：选题节点本地运行 Agent 并生成候选节点 → 用户从候选节点创建分支 → 提示词节点只保存任务与约束 → Agent 节点按发送时路径发起本地运行 → 输出脚本节点接收合法结果或由应用创建 → 用户可从候选或脚本结果继续建立分支。

| 需求 | M2 本地脚本目标行为 |
|---|---|
| F-04 选题目标 | 选题输出必须通过现有 `topics` Schema；有效结果由应用生成候选节点，每个候选绑定来源 artifact 与 0 基候选身份。候选是图节点，不是现行 M2 的候选端口。选题生成结果后沿用内容/执行锁定规则。 |
| F-05 提示词目标 | 提示词节点保存任务与约束，不直接运行。运行入口来自其下游 Agent 节点；提示词可在无活动运行锁时编辑，已发送运行仍使用原快照。 |
| F-07 输出结果 | 合法选题结果原子生成候选节点。合法 `script` 结果在无指定输出节点时自动创建脚本节点并关联结果；指定的空脚本节点自动接收；指定脚本节点已有版本时建立待确认结果，确认后追加版本，取消不改动已有内容。 |
| F-15 Agent 与输出节点 | Agent 节点是本地运行入口；每个 Agent 至多一个直接脚本输出节点。输出契约固定为现有 `script` Schema（版本 1）；Agent 只能提交受限 `reply`，不能直接调用通用写图命令。新建或追加脚本结果均不自动执行下游。 |
| F-16 执行位置 | 本阶段仅本地 Agent；云端账户、上传、隔离、费用及远程服务均不纳入 M2，留在 RM-019 评估。 |
| F-17 上下文与改挂 | 每次发送按当时图路径重建祖先、候选、提示词、任务约束与目标契约；改挂只影响之后的运行。运行快照及其来源不可因后续图变更而改写。 |
| F-18 本地工具边界 | Agent 自身提供其本地文件/Bash 等能力；AudioUI MCP 只提供受运行授权的应用交互。工作区路径边界与 Bash 协作式门禁保持不放宽，不宣称操作系统沙箱。 |

**本阶段图契约**：节点类型为 `topic`、`candidate`、`prompt`、`agent`、`script`；允许的连接仅为 `topic → candidate`（仅应用自动生成）、`candidate → prompt`、`prompt → agent`、`agent → script`、`script → prompt`。候选与脚本结果可分别连接多个后续提示词分支；单父、无环、所有写入经 Go 命令层。Agent 的直接脚本输出最多一个。其他类型组合由后端拒绝，前端只呈现权威快照与命令结果。

**版本与数据边界**：新工程使用 `project.json` v2；v1 工程不静默迁移，返回 `UNSUPPORTED_VERSION`，但不能阻止列出/新建/打开其他有效工程。M1 会话导入直接生成 v2 工程。候选身份由不可变 `topics` artifact ID 与 0 基索引共同确定；脚本版本追加引用内容寻址 artifact 与来源运行快照。`script` Schema 复用唯一的 `ValidateStructuredPayload`，不另复制 Schema。

**边界**：不改变视频节点/产物、`scene_dsl`、渲染导出或云端执行；AC-T-04 视频专项仍待后续评估，不以脚本测试替代。当前实现能力与本目标设计分别记录，旧版 M2-00～10 验收不表示本节已实现。

## 2. 背景与问题

### 2.1 现状

内容生产被拆成四段：聊天里出选题和文案、文档里改稿、浏览器里生成素材、剪辑软件里成片。每段之间的上下文靠人搬运。

### 2.2 问题

| 问题 | 影响 |
|---|---|
| 流程不可见 | 不知道自己做到哪一步，返工多 |
| AI 结果不可复现 | 同一提示词两次结果不同，无法回滚 |
| 无法复用 | 每期从零开始，第二期不比第一期快 |
| 工具成本高 | 订阅制 AI 视频工具按月计费 |
| 数据不在本地 | 工程、素材、记录被平台锁定 |

### 2.3 为什么现在做

- Claude Code 的 stream-json 与权限协议可以驱动一次性运行，并由 App 注入上下文。
- WebCodecs + 浏览器 Canvas 可以本地确定性出片。
- 本机 MCP 可以让 Agent 以结构化方式操作工程。

## 3. 目标与成功指标

### 3.1 目标

1. 把「选题 → 脚本 → 画面 → 配音 → 导出」固化成一条可复用的链路。
2. 让 Agent 的每次产出可追溯、可应用、可回滚。
3. 让第二条同模板视频的制作时间显著低于第一条。

### 3.2 指标

| 指标 | Baseline | 目标 | 测量方式 |
|---|---|---|---|
| 第一条完整视频 | — | 完成首条完整视频 | 里程碑记录 |
| 单条视频制作时间 | 未测量 | ≤ 3 小时 | 手动记录起止 |
| 同模板第二条 | — | ≤ 2 小时 | 手动记录 |
| 连续更新 | 0 | 形成稳定更新节奏 | 发布记录 |
| 渲染失败率 | — | < 5% | 本地日志 |
| 运行中断可回看率 | — | 100% | 本地日志 |

> 本产品不采集远程遥测。以上指标通过本地日志与手动记录统计。

## 4. 用户与场景

### 4.1 目标用户

- 单人创作者，具备开发能力。
- 零预算或极低预算。
- Windows 11。
- v1 内容方向：音游作曲解析。

### 4.2 核心旅程

M2-00～10 的既有实现与验收是旧模型历史基线；下列流程是 M2-11～13 选定的本地脚本目标，已按任务分阶段实现，M2-11C 已于 2026-11-07 验收，M2-11D 已于 2026-11-07 通过用户验收，完整闭环仍未完成。

1. 新建工作台并创建选题节点。
2. 输入想法并运行本地 Agent；有效 `topics` 结果由应用生成候选节点，选题内容与执行锁定。
3. 从候选节点创建一个或多个提示词分支；提示词仅保存任务与约束。
4. 将提示词连接至 Agent 节点，从 Agent 节点发起本地一次性运行。
5. 发送时从当前路径构建上下文并冻结来源与输出契约；改挂只影响之后的运行。
6. 合法 `script` 结果无指定输出时自动创建脚本节点；指定空脚本节点时自动接收；已有脚本版本时先待确认。
7. 确认已有节点的新结果后追加不可变版本；取消不改变旧版本。新建或追加脚本结果后都不自动运行下游。
8. 从候选或脚本结果继续建立提示词分支，按需要由用户再次发起 Agent 运行。

本阶段不实现视频节点、渲染/导出或云端执行。
### 4.3 关键异常场景

| 场景 | 期望行为 |
|---|---|
| Claude CLI 未安装 | 启动提示安装指引，禁用 Agent 功能 |
| 运行中断 | 标记中断，运行历史可回看，重新执行节点 |
| 并发已满 | 进入队列，显示位置，可取消/调整顺序 |
| 渲染失败 | 保留旧预览，显示错误，不破坏工程 |
| 删除节点 | 预览影响面，级联删除下游，进回收站 |
| Agent 输出不合规 | 校验失败，保留原文，节点标红 |

## 7. 业务规则与异常

### 7.1 规则

> 本节描述 M2-11～13 已选定的目标规则；M2-11B 工程格式与图领域模型已于 2026-11-06 通过用户验收，M2-11C 发送快照、上下文与运行授权已于 2026-11-07 验收；M2-11D 受限输出事务实现与自检完成、待用户验收，M2-12A 新工作台尚未完成。M2-00～10 已验收旧模型的实际行为以其历史验收记录为准。

1. 图是单父森林：每个节点最多一个父；topic 必须无父且是树根；边不悬空。允许的节点连接矩阵以 [1.1](#11-新目标需求m2-本地脚本子范围已选定设计已验收功能未实现) 为准。
2. 可改挂节点及其子树只能经 Go 图命令校验；必须满足连接矩阵，成环、自连、跨工程连接和 topic 作子节点均拒绝。candidate 来源身份不可改写；改挂只改变未来运行的路径，不改变既有运行/结果来源。
3. topic 在有效 `topics` 结果生成候选节点后锁定内容与执行。prompt 仅保存任务与约束，不独立运行；无活动运行锁时可编辑。Agent 节点可在非运行期间再次运行；在途运行路径和绑定输出只读。
4. topic 的每个有效候选由应用生成一个独立 candidate 节点；连接 candidate 到 prompt 即确定该分支的选题来源，不再使用 `parentCandidate`。
5. 每个 Agent 至多有一个直接 script 输出节点；script 节点可作为后续 prompt 分支的上游。候选和脚本结果均可连接多个后续 prompt，禁止连接矩阵以外的类型组合。
6. 每次 Agent 执行一个运行；发送时冻结 topic root → Agent 的路径、candidate 来源、prompt 任务/约束、输出节点与 `script` 契约版本。改挂后新运行重建上下文；运行间不共享 Agent 上下文。超预算时目标任务完整保留，祖先按既有预算策略降级，仍超则拒绝。
7. 同一节点同一时间只允许一个运行；M2 全局单在途运行。
8. topic 结果验证通过后，由命令层原子写入不可变 `topics` artifact 并生成所有 candidate 节点；无指定脚本输出时，合法 `script` reply 原子创建 script 节点并关联结果；指定空 script 节点时自动追加首个版本；已有版本时创建待确认结果，确认时按冻结的目标版本追加新版本，取消不改动旧版本。所有 script 版本引用不可变 artifact。
9. 工作区按 topic 树共享；写入只允许当前运行节点增量目录；读取按当前路径叠加；其他 topic 树拒绝。Agent 工具范围不因节点模型变化而放宽。
10. 删除节点级联处理全部下游；增量与产物按既定回收策略处理。
11. 运行路径与指定输出节点只读；路径外兄弟分支可编辑；创建输出结果不会自动启动下游 Agent。
12. 任何写操作先校验后落盘；失败不得留下半成品。Agent 只提交受限 `reply`，不得通用写图；重放需幂等。
13. 选中节点与切换视图不改变图 revision、不广播快照；`activeNodeId` 仅用于恢复上次选中。

### 7.2 异常处理

| 异常 | 处理 |
|---|---|
| Agent 输出不符合 Schema | 节点标红，保留原文，不自动重试 |
| 应用重启时运行未完成 | 标记 `interrupted`，运行历史可回看，重新执行节点 |
| 改挂已有父的节点 | 提示影响面与上下文变化，确认后移动整个子树并标记下游 stale |
| 编辑运行/排队路径上的节点 | 拒绝并提示任务占用；路径外分支可编辑 |
| 编辑/再次执行已锁定节点 | 拒绝；提示新增下游节点或从候选端口开分支 |
| 渲染超时/崩溃 | 保留旧预览，记录日志，允许重试 |
| 磁盘空间不足 | 阻止导出，提示清理回收站 |
| 路径越界 | 直接拒绝，记录审计日志 |
| 应用产物时上下文已变 | 提示输入已变化，确认后仍可应用 |

## 8. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 3 秒（参考机）；1080p30 预览流畅；导出快于实时 |
| 资源 | 3 个活跃运行时内存 ≤ 1.5 GB；M2 全局单在途 |
| 上下文 | 默认预算 1,000,000 tokens；超预算按祖先降级或拒绝；记录估算与实际 usage |
| 可靠性 | 工程写入原子化；崩溃后可恢复；回收站 24 小时 |
| 兼容 | Windows 11 22H2+；系统 WebView2；不要求管理员权限 |
| 安全 | 仅监听 127.0.0.1；每运行独立 token；路径白名单；无远程遥测 |
| 隐私 | 不采集远程数据；日志仅本地 |
| 可用性 | 首次启动检测 CLI/WebView2；错误提示可执行 |
| 可维护 | 领域层可单测；适配器可替换；协议版本化 |

## 12. 变更治理
