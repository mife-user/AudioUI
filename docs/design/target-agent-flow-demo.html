比较指定输出、自动创建输出，以及改挂后发送新上下文。所有数据和执行均为本页模拟，不读取项目、不连接 Agent，也不会上传任何内容。

当前应用仍以 M2 候选端口和待应用为基线；此演示展示新目标，不能作为实现或验收证据。视频产物采用前端代码、DSL 或其他形式仍待确定。
