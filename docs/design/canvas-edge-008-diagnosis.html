画布错误 008：动态端口同步机制

用三个可切换的状态说明：工程里的连接、节点实际呈现的端口和 React Flow 的端口测量缓存是不同的数据。

这是独立机制示意，不运行 React Flow，不读取或修改工程，也不是修复实现。真实界面的时序可能不同；错误 008 的直接条件是计算连线时找不到指定端口。

修复计划关注点

  1. 候选或占位端口变化后通知 React Flow 重新测量。
  2. 在新端口完成测量前，不把依赖它的边交给 React Flow 计算；已有工程连接不能因此被删除。
  3. 避免同一候选产物在普通图刷新时反复清空；真实读取失败仍须禁用端口并提示。
