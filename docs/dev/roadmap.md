## 1. 用途与权威

本文件回答三个问题：

1. 现在做什么：当前批次与需求优先级。
2. 做到哪了：批次与需求的状态。
3. 什么暂时不做：暂存需求池及其触发条件。

边界：

| 内容 | 归属文档 |
|---|---|
| 需求是什么、为什么做 | [PRD](../prd.md) |
| 需求怎么实现 | [架构](../architecture.md) / [ADR](../decisions.md) |
| 界面怎么呈现 | [前端设计](../frontend-design.md) |
| Agent 怎么接入 | [Agent 协议](../agent-protocol.md) |
| 做到什么算通过 | [验收标准](../acceptance.md) |
| 开发怎么推进 | [开发流程](process.md) |

更新规则：

- 状态只能由用户确认后变更；变更必须有验收证据或明确决策。
- 不写开发日期、周数、工时或完成期限。
- 不删除已关闭条目；保留结论与原因。

## 7. 暂存需求池

### 7.1 定位

开发过程中出现、但当前无法处理的变动要求，统一进入本池。入池不等于拒绝，也不等于承诺；它保证要求不被遗忘，也不污染当前批次。

**入池条件（满足任一）**：

- 超出当前里程碑范围。
- 依赖未就绪（外部能力、协议、模型、格式）。
- 与已定 ADR 冲突。
- 成本或复杂度不适合当前批次。
- 需要外部版本或许可证评估。
- 用户提出但当前不规划。

**不入池**：

- 当前批次内的实现细节修正（走变更类型 A）。
- 阻断性问题（走缺陷流程，不压进池里）。
- 没有任何触发条件的空想（记录到讨论即可）。

### 7.2 字段

| 字段 | 说明 |
|---|---|
| ID | `RM-001` 起，不复用 |
| 标题 | 一句话说清能力 |
| 类型 | 需求 / 体验 / 技术债 / 风险 |
| 等级 | P0 / P1 / P2 / 待评估 |
| 来源 | 用户 / 开发 / 验收 / Agent / 外部依赖 |
| 提出日期 | 登记日期 |
| 影响 | F-xx、批次、文档、模块 |
| 暂缓原因 | 为什么现在不做 |
| 触发条件 | 什么情况下重新评估 |
| 建议版本 | v1.1 / v1.2 / v2 / 待定 |
| 状态 | 暂存 / 评估 / 已规划 / 已纳入 / 已拒绝 / 已废弃 |
| 关联 | ADR、PRD 条目、验收项 |

登记时追加到 [7.6 当前暂存条目](#76-当前暂存条目)：

```markdown
| RM-xxx | 标题 | 需求/体验/技术债/风险 | P0/P1/P2/待评估 | 建议版本 | 暂存 | 暂缓原因；触发条件 |
```

### 7.3 状态流转

```
暂存 → 评估 → 已规划 → 已纳入
  │       │
  ├───────┴──→ 已拒绝
  └──────────→ 已废弃
```

| 状态 | 含义 | 谁能改 |
|---|---|---|
| 暂存 | 已登记，当前不做 | 用户确认后登记 |
| 评估 | 正在判断可行性、成本、影响 | Claude 可提议，用户确认 |
| 已规划 | 已决定放入某个版本方向 | 用户 |
| 已纳入 | 已进入 PRD 与路线图，成为正式需求 | 用户 |
| 已拒绝 | 明确不做 | 用户 |
| 已废弃 | 条件消失或已被其他条目替代 | 用户 |

### 7.4 出池规则

条目从池中进入实现，必须依次完成：

1. 用户确认纳入。
2. 在 PRD 新增或修改 F-xx，并写变更记录。
3. 在验收标准补 AC。
4. 在路线图分配批次，状态改为「已规划」或「已纳入」。
5. 影响架构的，先新增 ADR。
6. 满足 DoR 后，才允许开工。

**不得**在未完成上述步骤时直接写实现代码。

### 7.5 评审规则

- 每个里程碑收口（S6）时逐条过池：保持、评估、规划、纳入、拒绝或废弃。
- 发版前确认没有「已规划但未纳入」的条目。
- 评审是事件驱动，不设日历周期。
- 同一需求重复出现时合并到原条目，不新建重复 ID。

## 9. 评审与更新规则

- **状态变更需证据**：AC 通过、评审记录、缺陷结论或用户明确决定。
- **评审触发**：里程碑收口、发版前、出现阻塞、用户要求；不按日历周期。
- **谁更新**：Claude 可起草与提议；状态与优先级由用户确认后写入。
- **不写时间**：不添加日期、周数、工时、完成期限；需要表达顺序时用批次与优先级。
- **不重复**：同一需求只保留一个 F-xx 与一个 RM-xxx；合并重复条目。
- **不删除历史**：已拒绝、已废弃条目保留，便于回看决策。
