# AI 视频生产业务调研与方向

> **状态**：用户确认优先评估“可控画面 + 按需生成式素材”的混合方向，继续使用现有 Claude Code 适配，不以自研 Agent 为前置条件；具体视频范围、供应商、工具、成本、输出契约和排期仍待 RM-020 评审。本文是调研与方向记录，**不表示视频能力已实现或验收**。
>
> **调研边界**：2026-11-10 经用户授权联网检索公开官方资料。网页全文抓取因安全校验未通过，以下事实主要来自搜索服务返回的官方页面索引和摘要，并非逐页核验全文；未下载模型或依赖，未上传素材，未调用真实视频生成服务。型号能力、参数组合、费用、地区可用性、数据留存和许可须在选型时查阅最新版官方文档并按授权验证。

## 1. 视频生产的共同环节

| 环节 | 输入及活动 | 应保留的结果 / 待设计内容 |
|---|---|---|
| 任务与素材 | 主题、目标受众、素材来源及使用权限；原音乐、录音、谱面、截图等按需提供 | 任务说明、素材清单及来源；不能假设全部素材可上传或商用。 |
| 文案 | 选题、资料和创作要求汇合，形成解说脚本 | 可编辑脚本、版本和来源；事实及引用仍需人工核对。 |
| 分镜 | 将脚本拆成画面、旁白、预估时长、视觉要求和素材引用 | 分镜结果及其来源；实际音频时长可促使重新调整。 |
| 画面 | 组合已有截图/视频、波形/图表/程序动画，或按需生成图片、短视频镜头 | 每个镜头的素材、版本、引用和必要的生成信息；素材是否生成或导入不应隐藏。 |
| 音频与字幕 | 选用原声、录音或经批准的配音方式，制作并校对字幕 | 音频与字幕及其时间信息，供后续合成和单独修改。 |
| 合成与交付 | 确定片段顺序和时长，检查画面、字幕及音频，并交给剪映精修 | 视频、字幕、脚本和所需素材清单；导出形式和兼容性须评审并实测。 |

CapCut 的公开资料将脚本、分镜、场景生成、编辑、音频与导出作为连续工作环节。[1] Adobe 的资料展示多轨时间线，以及把生成的镜头放入时间线进行编辑。[2] 这些是具体产品的流程证据，不代表 AudioUI 必须复制其交互或实现完整剪辑器。

## 2. 与多上游相关的调研发现

1. Runway 图生视频示例同时提供图片和文本提示词，并以任务方式取得结果。[3] 单个生成步骤可以同时依赖不同类型输入。
2. 阿里云百炼的公开索引说明视频生成可使用图片、视频或音频参考，也列出某些参考素材和首尾帧模式不能混用的限制。[4] 具体限制属于所选模型/接口及参数组合，不应变成画布连线时的通用类型限制。
3. Runway 工具节点资料将视频与音频合成作为一个需要两种输入的步骤。[5] 这不要求所有执行节点都具有自然语言主任务。
4. Runway 的资料区分提交任务、查询状态和获取输出，并提示输出链接有时效。[3][6] 后续若接入远程工具，须设计任务状态、取消/失败、结果回收和持久化，而非把临时链接当作永久产物。
5. 多输入也可通过单父节点的附件/素材清单表示；DAG 并非调用视频模型的技术前提。AudioUI 选择显式多上游，是为了把依赖、来源和版本清楚地放在图上；运行输入的适用性须另行校验。

## 3. 用户确认的方向与边界

- **混合生产**：对谱面、BPM、波形、文字等需要准确控制的内容，优先评估已有素材及可控渲染；需要氛围或叙事的镜头按需使用生成式图片/视频；保留交给剪映精修的方向。不将所有画面强制交给生成模型，也不排除未来自动接入。
- **Agent**：继续使用现有 Claude Code 适配；不因视频需求先自研 Agent。当前应用仅实现既有 `topics`/`script` 闭环，**没有现成的视频模型调用、视频产物或渲染导出闭环**；将来仍需评审并接入相应受控工具、权限和输出契约。
- **图与运行**：已确认任意阶段、多上游、无环的连接目标；可连接不代表一定可运行。运行时按任务/工具的实际输入契约检查，明确输入选择与版本，不得静默删除不兼容连线；参见 [ADR-030](../decisions.md#adr-030-多上游无环图与版本引用草案)。
- **本地与远程**：ComfyUI 的公开示例包含文本/图片生成视频工作流，运行需要相应模型与环境。[8] 本地工具的硬件和分发约束、云端调用的上传/费用/数据处理须分别评估；既不假设可在用户机器运行，也不宣称云端素材不离开本机。
- **未决定**：第一条视频闭环是否必须直接调用视频生成模型、先导入外部生成素材还是两者并行；是否引入其他受控画面技术或修订 DSL、节点类型、服务/模型、付费及授权策略、实现批次。现行 [ADR-007](../decisions.md#adr-007-场景-dsl-而非模板参数) 和路线图 M3 的场景 DSL 仍是既定基线；混合方向不自动撤销该决策，若需改变须另行评审。RM-020 保持评估，用户确认方向不等于纳入当前工作台实现。
- **安全与证据**：不在持有应用凭据或本机权限的环境中直接运行任意生成代码；不因图汇合自动扩大文件读取授权。若以后做真实网络、上传、模型调用或付费测试，须在对应操作前取得明确授权，索引摘要或脚本测试不能替代视频验收。

## 4. 后续评审清单

- 明确首条视频闭环的输入、交付物、允许人工参与的位置，以及“导入既有素材”和“直接调用生成服务”的范围和顺序。
- 对候选工具分别核实最新输入组合、支持格式、视频/音频处理、取消/重试、输出有效期、地区可用性、价格和使用许可；不把搜索摘要当作接口契约。
- 明确素材与镜头的来源、不可变版本、时间信息、再生成影响和结果回收；视频具体版本语义另行设计。
- 分别覆盖离线受控替身、真实服务/收费与上传授权、视频播放、导出及剪映导入；不得以网页原型或脚本用例替代视频专项 AC-T-04。
