## 1. 实现范围

- 新增 run-scoped MCP `get_chain`、`get_graph`、`get_node`、`list_node_types`、`validate`、`read_artifact`、`reply`；无运行 scope 时保留 M1 工具入口。
- 图和节点读取只返回当前运行路径；workflow 读取适配器校验工程、树及真实父子路径，路径外节点拒绝访问。
- `validate` 复用 M2-05 Schema 校验；结构化 `reply` 从 MCP 原始 arguments 读取 payload，并通过 workflow 创建 pending。无效 Schema 的 JSON payload 原样保留为 invalid pending；不提供写图或 apply 工具。
- 工具操作通过活动运行租约；reply 写入与运行终止互斥。真实 RunService/CLI 生命周期接线留在 M2-07。
- `read_artifact` 仅读取路径祖先轮次引用的产物，按 `Round.Kind` 授权；topic 产物先过滤当前路径所选候选。相同 artifact ID 的视图冲突时拒绝；按 UTF-8 字节边界分块，每块最多 16 KiB。
- 新 MCP 工具加入自动允许策略；服务端仍执行 run scope 与活动状态校验。
