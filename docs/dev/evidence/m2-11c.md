## 实现范围与验收映射

- `workflow.BeginRun` 在图命令共用锁内生成并返回 `RunExecutionSnapshot`；Topic 与 Agent 可运行，Prompt 仍不能独立运行。运行记录持久化快照，运行 scope 深拷贝快照。
- Agent 运行锁覆盖发送路径和唯一直接 Script 输出节点；锁释放后可编辑。新增测试覆盖输出节点在途改挂拒绝、路径锁定及无关兄弟分支可编辑。
- v2 上下文从快照读取 Candidate 来源 artifact 的单项、当前 Prompt 的完整任务/约束、祖先 Script 的精确不可变版本及输出绑定基准；不要求中间 Prompt 有旧式 applied round。缺少 Candidate/Script 版本或 artifact 时显式失败。预算只降级祖先产物，当前任务不截断。旧 Topic golden 保持不变。Agent 的 Script reply 在当前阶段明确返回 `OUTPUT_COMMIT_UNAVAILABLE`，不落 pending/图。
- run-scoped MCP 的图/节点/产物查询以发送快照为授权来源，不读取实时工程图替代快照；Candidate 只返回所选对象，Script artifact 只允许快照指定版本。通用文件工具不再注册到 run-scoped MCP，M1 legacy MCP 工具表保留。
- 本地内置文件工具读取限运行路径祖先与 exe 同级共享 `runtime/`，写入限当前节点 `steps/`；runtime 不可写，越界路径拒绝。Bash 继续作为 RM-017 协作式门禁，不宣称 OS 沙箱。
