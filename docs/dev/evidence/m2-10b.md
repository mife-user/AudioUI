## 实现摘要

- 控制台按当前工程展示 pending/invalid 摘要，选中后按需读取正文；有效 topics 展示候选预览，invalid 展示原文和校验错误且只能丢弃。
- 应用/丢弃防重复提交，成功后刷新工作台；仅在用户确认后以 `force=true` 处理参数或上下文哈希冲突。
- 新增工程作用域 `GetTopicCandidates(nodeId, projectId)`，从最新已应用 topics round 的 artifact 读取候选，校验 round、artifact 和 payload，返回稳定 0 基索引及候选字段。
- 画布候选端口由已应用候选驱动；候选异步加载及 handle 测量时序回归已补充测试。
