## 1. 实现范围

- pending 索引与原文分离；无效 JSON/Schema 仍保存原始字节、错误和 `invalid` 状态，不可应用。
- 实现 `topics`、`script` 最小 Schema；payload 上限 256 KiB，`request_id` 上限 128 字节；按 run/request 内容做幂等与冲突判定；同一运行最多一个结构化结果，每树最多 50 条活动 pending。
- Apply 重算参数/祖先哈希，force 仅绕过哈希差异；成功后规范化并写 CAS artifact、追加轮次、锁定节点并传播后代 stale。Discard 幂等且保留历史原文。
- 新增 `pending.txn.json` 跨文件事务恢复；工程加载按 base/target revision 回滚未提交事务或恢复已提交索引、原文和 artifact；状态不明或恢复失败则阻断打开。
- Handler/Wails 绑定提供 pending 列表、详情、应用与丢弃。结构化创建入口留给 M2-06 `reply` 接线；本任务未实现 MCP 工具或 UI。
