## 实现范围

- 收起态 Agent 状态胶囊的非按钮区域支持指针拖动和键盘方向键移动。
- 展开按钮仍只负责展开，不会启动拖动。
- 收起胶囊与展开面板共享会话内位置；切换形态及视口缩放后按当前控件尺寸重新夹取。
- 拖动取消、形态切换和组件卸载时清理指针监听；运行、请求、待处理和面板内容状态不因位置变化而重置。
- 位置仅保存在组件会话状态，不写工程，应用重启后恢复默认位置。
