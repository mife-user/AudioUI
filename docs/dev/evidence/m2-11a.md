## 浏览器操作与结果

使用本机 Microsoft Edge headless/CDP 操作本地原型，未安装依赖、访问网络或启动真实 Agent/CLI。

| 检查 | 结果 |
|---|---|
| 1440×1000 布局 | 通过；页面 `scrollWidth=1440`，标题及工作流节点正常显示 |
| 未指定输出 | 合法模拟 `script` reply 自动创建并关联 Script v1 |
| 已有输出版本 | 切换到候选 B 后形成绑定版本 1 的待确认结果；运行历史保留 A/B 来源；取消后原版本不变 |
| 指定空 Script | 合法模拟 reply 自动写入首个版本 |
| 非法 reply | 显示 `SCHEMA_INVALID`；不创建待确认结果、不修改已有版本 |
| 确认时版本冲突 | 基准版本变化后显示 `OUTPUT_VERSION_CONFLICT`；不追加待确认 payload |
| 分支切换 | 候选分支可切换，运行来源展示保持对应分支 |
| 1024×700 布局 | 通过；文档与 body 宽度均为 1009 px，无页面级横向溢出 |
| 浏览器运行时错误 | 无；控制台错误列表为空 |
