## 实现摘要

- 新增 workspace/run API 封装、Zustand stores 与 workspace bridge：先订阅事件再加载快照，按工程 generation 隔离迟到事件/响应；按 seq 去重、缓冲并检测缺口，保留快照同步失败的重试状态。
- 新增工程切换、新建和打开界面；运行在途时禁用工程切换，并显示后端 `BUSY` 竞态错误。
- 工作台按快照展示工程状态；控制台按 runId 查看运行历史、transcript、工具事件、运行状态和元数据；活动运行支持中断、权限及问题响应，历史只读。
- 删除旧 M1 自由聊天/恢复入口及其专属 store、API、组件与测试；控制台不提供自由聊天输入，待处理页为空状态，画布保留 M2-09 占位。
