## 实现摘要

- 画布从 `WorkspaceSnapshot` 节点关系、Candidate 来源、Script 版本和 Go 派生 `chains` 构建五类节点及边；Candidate 只能由应用快照呈现，不作为手工创建/改挂目标。
- Prompt 节点编辑任务与场景数/时长约束，防抖串行保存并保留失败输入。Agent 启动前 flush 当前权威路径上的 Prompt；保存失败或快照未同步时不调用运行入口。
- 只有 Agent 节点提供本地运行入口；节点从快照消费运行锁、全局 BUSY、运行状态和直接 Script 绑定。无绑定时显示自动创建契约；指定空 Script 显示等待首个结果；Script 显示不可变版本和来源运行。
- Connect 总是把过渡字段 `parentCandidate` 设为 `null`，提交由 Go 判定；前端不复制连接矩阵或乐观创建边。候选读取加载/错误期间仍保留快照已有 Candidate Handle 和边。
